# Vitalize Estética Avançada — Landing Page

Landing page editorial e responsiva desenvolvida para a Vitalize Estética Avançada, em Criciúma/SC.

## Executar localmente

1. Instale as dependências com `npm install`.
2. Inicie com `npm run dev -- --port 3003`.
3. Abra `http://localhost:3003/`.

## Verificações

- `npm run lint`
- `npm run build`

## Conteúdo e imagens
